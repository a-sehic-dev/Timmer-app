========================================
  iPHONE & ANDROID — Instructions
========================================

ANDROID — USE THE APK (recommended for Android)
------------------------------------------------
Install TimerApp.apk from this ZIP — fully offline, real app icon.
Gmail blocks APK files — use Google Drive, USB, or Telegram.
Full step-by-step guide: README_ANDROID.txt


iPHONE — USE THE LINK (recommended)
--------------------------------------
Open in Safari (iPhone) or Chrome (Android/Samsung):

  https://web-a-sehic-devs-projects.vercel.app

NO login required. NO Vercel account. NO App Store.
Just tap the link — timer opens instantly.


INSTALL AS APP (home screen icon)
----------------------------------

iPhone (Safari):
  1. Open the link in Safari
  2. Tap Share button (square with arrow)
  3. Tap "Add to Home Screen"
  4. Tap "Add"
  5. Open timer from home screen icon — no URL bar

Android / Samsung (Chrome):
  1. Open the link in Chrome (NOT file manager)
  2. Tap ⋮ (three dots, top right)
  3. Tap "Install app" or "Add to Home screen"
  4. Confirm
  5. Open timer from home screen icon — runs like a real app


BACKUP — HTML FILE (if link doesn't work)
------------------------------------------
1. Extract TimerApp_Delivery.zip
2. Send TimerWeb_iOS.html to your phone (email, AirDrop, Drive)
3. Open with Safari or Chrome
4. Add to Home Screen as above


HOW TO USE THE TIMER
---------------------
1. Set Actual Duration (real minutes)
2. Set Display Time (shown minutes)
3. Tap START TIMER
4. [+] adds 1 min display + 2 min actual
5. [−] removes 1 min display only
6. STOP stops the timer

Speed = Display ÷ Actual (updates instantly on +/−)


TIPS
----
- Use Chrome on Samsung, Safari on iPhone
- Do NOT open .exe or .zip in file manager — use the link
- Keep screen on during long timers (may pause if locked)
- Same timer logic as Windows version
