========================================
  ADJUSTABLE SPEED TIMER — User Guide
========================================

Thank you for your order! This is a Windows desktop app.
No Python or installation required — just run the .exe file.


HOW TO OPEN THE ZIP FILE
-------------------------
1. Download TimerApp.zip from Upwork.
2. Right-click TimerApp.zip → "Extract All..." (or "Extract Here").
3. Choose a folder (e.g. Desktop) and click Extract.
4. You will see:
   - TimerApp.exe      (the app)
   - README.txt        (this file)
   - INTEGRATION.txt   (optional iOS/Swift porting guide)


HOW TO RUN THE APP
-------------------
1. Double-click TimerApp.exe.
2. If Windows shows a security warning ("Windows protected your PC"):
   - Click "More info"
   - Click "Run anyway"
   (This is normal for new .exe files from freelancers.)

3. The timer window will open. No install wizard — it runs immediately.


HOW TO USE THE TIMER
---------------------
SETUP (before starting):
  - Actual Duration  = real time that passes (in minutes)
  - Display Time     = time shown on the countdown (in minutes)
  - Click "START TIMER"

Example: Actual 60, Display 90 → display counts down 90 minutes
         over 60 real minutes (speed = 1.5x)

WHILE RUNNING:
  - Big blue number  = Display time (what you see)
  - "Actual: ..."    = real time remaining
  - "Speed: ..."     = Display ÷ Actual (auto-calculated)

  [+] button  = Add 1 min to Display, add 2 min to Actual (speed recalculates)
  [-] button  = Remove 1 min from Display only (speed recalculates)
  [STOP]      = Stop the timer

Keyboard shortcuts:  +  add time  |  -  reduce  |  q  stop  |  Enter  start


NOTES
-----
- This is a Windows PC app (not iPhone/Android).
- You can move TimerApp.exe anywhere — Desktop, folder, USB.
- No internet connection needed.
- To run again later, just double-click TimerApp.exe.
