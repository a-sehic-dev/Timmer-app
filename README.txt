========================================
  ADJUSTABLE SPEED TIMER — User Guide
========================================

Two versions included — same logic, different platforms.


WHAT'S IN THE ZIP
-----------------
  TimerApp.exe       → Windows PC (double-click to run)
  TimerWeb_iOS.html  → iPhone/iPad (open in Safari)
  README.txt         → This file
  README_iOS.txt     → Detailed iPhone instructions
  INTEGRATION.txt    → Swift code guide (optional, for developers)


WINDOWS — QUICK START
----------------------
1. Double-click TimerApp.exe
2. If Windows warns you: More info → Run anyway
3. Set Actual + Display → START TIMER
4. Use +, −, STOP buttons (or keyboard +, −, q, Enter)


iOS / iPhone — QUICK START
---------------------------
Best: open this link in Safari on your iPhone:
  https://a-sehic-dev.github.io/Timmer-app/

Or open TimerWeb_iOS.html in Safari (see README_iOS.txt).
Tip: Share → Add to Home Screen for an app icon.


HOW THE TIMER WORKS (both versions)
------------------------------------
  Actual Duration  = real time that passes
  Display Time     = time shown on countdown
  Speed            = Display ÷ Actual (auto-calculated)

  [+]  Display +1 min, Actual +2 min — speed recalculates instantly
  [−]  Display −1 min, Actual unchanged — speed recalculates instantly

Example: Actual 60, Display 90 → 90 min display counts down
         over 60 real minutes (speed = 1.5x)


NOTES
-----
- Windows .exe does NOT run on iPhone — use the web version or the link.
- Web version needs Safari (Chrome on iOS also works).
- No Python or coding needed.
