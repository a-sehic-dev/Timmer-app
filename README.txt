HOW THE TIMER WORKS
-------------------
  Actual Duration  = real time that passes (minutes)
  Display Time     = time shown on countdown (minutes)
  Speed            = Display ÷ Actual (auto-calculated)

  [+]  adds 1 min to Display + 2 min to Actual (speed updates instantly)
  [−]  removes 1 min from Display only (speed updates instantly)
  STOP stops the timer

Example: Actual 60, Display 90
  → display counts down 90 minutes over 60 real minutes
  → speed = 1.5x
