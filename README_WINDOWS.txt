========================================
  WINDOWS PC — Instructions
========================================

FILE TO USE: TimerApp.exe


STEP 1 — EXTRACT THE ZIP
-------------------------
1. Right-click TimerApp_Delivery.zip
2. Click "Extract All..."
3. Choose Desktop (or any folder) → Extract


STEP 2 — RUN THE APP
---------------------
1. Double-click TimerApp.exe
2. If Windows shows "Windows protected your PC":
   - Click "More info"
   - Click "Run anyway"
   (Normal for new apps — safe to run)

3. Timer window opens immediately. No installation wizard.


STEP 3 — USE THE TIMER
-----------------------
SETUP:
  Actual Duration  = real time in minutes (e.g. 60)
  Display Time     = countdown shown on screen (e.g. 90)
  Click "START TIMER"

WHILE RUNNING:
  Big blue number  = Display time remaining
  "Actual: ..."    = real time remaining
  "Speed: ..."     = Display ÷ Actual

CONTROLS:
  [+]  Display +1 min, Actual +2 min
  [−]  Display −1 min, Actual unchanged
  STOP = stop timer

KEYBOARD SHORTCUTS:
  +  = add time
  -  = reduce display
  q  = stop
  Enter = start


NOTES
-----
- Works on Windows 10/11
- No internet needed
- Move TimerApp.exe anywhere — Desktop, USB, folder
- TimerApp.exe does NOT work on iPhone/Android
  → use the mobile link in README.txt instead
