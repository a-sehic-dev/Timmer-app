========================================
  iOS / iPhone — How to Use (Safari)
========================================

OPTION A — OPEN THE LINK (easiest)
-----------------------------------
If Sedin sent you a link (GitHub Pages), open it in Safari on your iPhone:

  https://a-sehic-dev.github.io/Timmer-app/

Then tap Share → "Add to Home Screen" for an app-like icon.


OPTION B — OPEN THE HTML FILE
------------------------------
1. Unzip TimerApp_Delivery.zip on your computer or iPhone.
2. Transfer TimerWeb_iOS.html to your iPhone (AirDrop, email, iCloud Drive, Files).
3. Open the file in Safari (tap and hold → Open in Safari).
4. Tap Share → "Add to Home Screen" — timer appears like an app.


HOW TO USE (same logic as Windows)
-----------------------------------
1. Set Actual Duration (real time in minutes)
2. Set Display Time (countdown shown on screen)
3. Tap START TIMER
4. [+] adds 1 min display + 2 min actual (speed recalculates)
5. [−] removes 1 min from display only (speed recalculates)
6. STOP stops the timer

Speed = Display ÷ Actual (auto-calculated)


TIPS
----
- Works in Safari on iPhone/iPad — no App Store needed.
- Keep Safari open (or Add to Home Screen) while timer runs.
- If screen locks, timer may pause — keep phone awake for long sessions.
