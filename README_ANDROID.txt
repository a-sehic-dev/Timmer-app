========================================
  ANDROID APK — Install & Use
========================================

This is a REAL offline Android app — not a web link.
No internet needed after install. No Google Play. No Vercel. No account.
Works forever, even if the web link goes offline.


WHAT YOU NEED
-------------
  TimerApp.apk   (inside TimerApp_Delivery.zip — extract the ZIP first)

NOTE: Gmail and many email apps BLOCK .apk files for security.
Use Google Drive, USB, or Telegram instead (see below).


METHOD 1 — GOOGLE DRIVE (recommended)
--------------------------------------
ON YOUR COMPUTER:
  1. Extract TimerApp_Delivery.zip
  2. Go to drive.google.com and sign in
  3. Click New → File upload
  4. Select TimerApp.apk
  5. Wait until upload finishes

ON YOUR ANDROID PHONE:
  1. Install the Google Drive app (Play Store) if you don't have it
  2. Open Drive → find TimerApp.apk
  3. Tap the file → Download (arrow icon)
  4. When download finishes, tap Open or go to:
     Files app → Downloads → TimerApp.apk
  5. Tap Install

  If Android blocks install:
    Settings → Security → Install unknown apps
    → turn ON for "Drive" or "Files"
  6. Tap Install → Open
  7. The Timer icon appears on your home screen


METHOD 2 — USB CABLE
--------------------
  1. Connect phone to computer with USB cable
  2. On phone: choose "File transfer" / "MTP" (not "Charge only")
  3. On computer: open phone storage → copy TimerApp.apk to Downloads
  4. On phone: Files → Downloads → tap TimerApp.apk → Install


METHOD 3 — TELEGRAM / WHATSAPP
-------------------------------
  1. Send TimerApp.apk to yourself (Saved Messages in Telegram works well)
  2. On phone: open the chat → tap the file → Download → Install
  Email often blocks APK — use Drive or Telegram instead.


METHOD 4 — DIRECT FROM ZIP ON PHONE
------------------------------------
  1. Copy TimerApp_Delivery.zip to phone (Drive works for ZIP files)
  2. Use a file manager (Files, ZArchiver, etc.) to EXTRACT the ZIP
  3. Find TimerApp.apk inside → tap → Install


VERIFY IT'S TRULY OFFLINE
--------------------------
After install:
  1. Turn on Airplane mode (or turn off WiFi + mobile data)
  2. Open the Timer app from your home screen
  3. Set times and start the timer — it should work normally

If it works in airplane mode, you have a permanent offline app.
No server. No link. No hosting needed. Ever.


HOW TO USE THE TIMER
--------------------
Same as the iPhone/web version:

  Actual Duration  = real minutes that pass
  Display Time     = minutes shown on countdown
  Speed            = Display ÷ Actual (auto)

  Tap ⚙ (gear) for settings — set Actual + Display
  [+]  adds 1 min display + 2 min actual
  [−]  removes 1 min display only
  START / STOP on the main screen

When timer finishes: continuous alarm until you tap STOP or Cancel.


TIPS
----
- Default: Actual 45 min, Display 30 min
- Keep screen on during long timers
- iPhone users: keep using the web link (see README_MOBILE.txt)
- To reinstall or update: tap the APK file again
- Uninstall: long-press app icon → Uninstall (like any other app)


TROUBLESHOOTING
---------------
"Can't install" / "Blocked":
  → Settings → Security → Install unknown apps → allow Drive or Files

"Parse error":
  → Re-download the APK — file may be corrupted or incomplete

App won't open:
  → Uninstall → reinstall from APK
